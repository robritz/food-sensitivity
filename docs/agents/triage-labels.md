# Triage Label Vocabulary

The five canonical triage roles, using the default label strings:

| Role | Label |
|---|---|
| Needs triage | `needs-triage` |
| Needs more info | `needs-info` |
| Ready for an agent to implement | `ready-for-agent` |
| Ready for a human to implement | `ready-for-human` |
| Won't fix | `wontfix` |

Since issues are local markdown files (see `issue-tracker.md`), a "label" is a `labels:` frontmatter field on the issue file rather than a tracker-native label.
