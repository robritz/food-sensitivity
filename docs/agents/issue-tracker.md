# Issue Tracker

Issues for this repo live as **local markdown files**, not on an external tracker.

- Location: `.scratch/<feature>/issues/<issue-slug>.md`
- One file per issue.
- No external account or CLI is required — skills read and write these files directly.
- PRs-as-a-request-surface: **off** (not applicable — no GitHub remote for this repo).

This convention was chosen because the repo is a fresh solo project with no GitHub remote yet.
